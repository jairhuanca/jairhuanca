# Jair Huanca
**Desarrollador Full Stack | Egresado de Computación e Informática | Estudiante de Ingeniería de Sistemas**

Me dedico al desarrollo de software con un enfoque integral, abarcando desde el diseño de interfaces hasta la arquitectura del backend y la gestión de bases de datos. Busco siempre construir soluciones eficientes y escalables.

### Sobre mí
- Actualmente estoy desarrollando mi proyecto de tesis: una plataforma web que integra **FastAPI** y **React**, automatización de flujos con **n8n** y pasarela de pagos con **Culqui**.
- Cuento con experiencia práctica en la construcción de aplicaciones web, desarrollo móvil para Android y programación de servidores por sockets.
- Fuera del entorno de programación, dedico mi tiempo libre a practicar natación y jugar fútbol.
